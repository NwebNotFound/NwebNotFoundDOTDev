# Lofi Radio – Audio Sources

Checked 2026-11-03; every URL returned HTTP 200 and the license was read from the page itself. No audio is stored in this repo. Download from the source and host it in R2/your own storage, and show credits in the app (credits page + now-playing).

Reference track (Nils' sample): 49.6 s, 32 kHz, no ID3 tags, calm and slow lofi. Picks below are calm, instrumental chill and lofi tracks.
