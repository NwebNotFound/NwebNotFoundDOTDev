# Runtime performance (jank): before / after perf/runtime-jank

Measured locally with `scripts/perf-runtime.mjs` (Playwright Chromium + CDP), main (dd50cd7) against this branch. Both ran `wrangler dev` on the same machine with the same empty local D1, so API data is empty and data-driven images and 3D models aren't included. Settings: CPU throttled 4x; 375 = mobile (touch, DPR 2), 1280 = desktop.
- **Idle main thread %:** CDP TaskDuration over 3 s without input and without a rAF sampler (always-running animations and timers).
- **Main thread while scrolling %:** the same during 3 s of wheel scrolling; dropped frames = frames over 50 ms.
- **LCP, CLS, TBT:** load metrics, TBT from long tasks up to 4 s after load.
- **INP proxy:** the slowest Event Timing entry for one tap or click on the nav toggle; "–" means none was registered.
- **`*`:** main-site LCP, CLS and TBT are medians of 3 runs per side after the final font change. The other values come from one full run per side.

Headless Chromium composites in software, so the scroll FPS (60 in every case) does not show GPU paint cost. The main-thread numbers show the cause of the jank directly.

## Causes found and fixed
| Cause | Where | Cost before | Fix |
|---|---|---|---|
| `ping`/`sm-ping` animated `box-shadow` (live dot) | main `/`, mc `/` and every live chip | style recalc every frame; on mc also a layout every frame | ring on `::after` with transform + opacity (composited), same spread and timing |
| `sm-shadow-pulse` on an **inline** span | main `/` hero | ran on the main thread every frame; its `scaleX` never applied to an inline box | opacity only, looks the same |
| old inline `.dot.on` box-shadow `pulse` in `worker.js` MC_CSS | mc pages | would apply again under the new theme rule | overridden in theme-v2 (`animation: none; box-shadow: none`) |
| Monocraft preloaded on every mc page but unused since theme v2 | mc shell | 2 wasted font downloads; the used fonts loaded late | mc shell preloads the 4 faces it uses |
| Turnstile `api.js` loaded on every `/guestbook` and market item page | guestbook, `/markt/<item>` | third-party script and frame for every visitor | loaded on demand (`render=explicit`) once the signed-in form is shown |
| 3D skin viewers: one WebGL loop at 60 fps each (up to 6) | mc pages with live models | full frame rate for slow idle/walk animations | capped at 30 fps (`FRAME_MS`); still frames and fallback unchanged |
| decorative loops keep running off screen | both heroes | ticked while reading further down | hero gets `is-off` via IntersectionObserver; loops pause, scroll-driven parallax keeps going |
