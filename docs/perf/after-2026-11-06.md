# Site performance after perf/site-requests — 2026-11-06

Measured locally, not live: `wrangler dev` of `origin/main` (163ecb7) and of branch `perf/site-requests`, same machine, same empty local D1 (API data is empty on both, so data-driven images differ from production). Script: `scripts/perf-measure.mjs` (Playwright Chromium + CDP). Same 13 pages and widths as `perf/baseline-2026-11-05.md`.

- **Cold** = fresh browser context. Requests = every network request, including redirect hops (e.g. `/mc-icon/v2/*` 302 → jsDelivr) and cross-origin.
- **Warm** = a second navigation in the same context. "On wire" = requests not served from the browser cache; the number in brackets is how many of them were 304 revalidations on main.
- KiB = summed CDP `encodedDataLength`.
- This is not comparable 1:1 with the live baseline numbers (different method). A live re-measure after deploy is still needed.
